# 《雾汀生物 · 白班与夜班》

雾系列的跑团游戏（桌面角色扮演）。主持人 + 2–4 名玩家，
一局约 3–4 小时（可分两次跑完）。

雾汀生物是一家生物科技公司，雾汀市郊的一栋楼。
对外，它研究雾岛的雾兽；实际上，它收容、研究从雾岛育种所
孵出来的雾兽，最高机密就是雾岛之主。

昨晚，雾岛之主的饲养室警报响了。今早，研究员陈默失踪了。
白班要应付这一天，夜班要查清楚夜里发生了什么，
而公司外面，记者和警察也闻风而来了。

## 核心玩法：白班与夜班由不同玩家扮演

这是这个游戏和别的跑团不一样的地方。

- **白班玩家**：白天在公司里，处理日常、应付来访、写交班表。
  他看到的一切，夜班玩家都看不到。
- **夜班玩家**：晚上来上班。他没见过白天发生的事，
  只能读白班留下的**交班表**和**保安登记**（客观记录，谁几点进出、
  带了什么走），推断白天到底发生了什么，再去处理夜里的异常。
- 白班写什么、漏什么、撒什么谎，夜班全靠交班表 + 保安登记反推。
  两个人明明是同事，却像在解对方的谜。

**外来线**：记者和警察从公司外面查。记者想发表，警察在查失踪案。
他们看到的和员工线完全不一样，但查的是同一件事。

## 怎么玩

**人**：一名主持人（人类或 AI），2–4 名玩家。
最少两人：一个白班，一个夜班。人多可以加记者、警察。
主持人讲场景、扮演 NPC、掷骰子判定；玩家说自己要做什么。

**在哪里玩**：对话框里就能玩。主持人把场景描述贴过去，
玩家回一句“我要做什么”，主持人按规则判定、讲结果。
白班和夜班玩家轮流行动，中间只通过交班表交流——
主持人把白班写好的交班表贴给夜班，夜班再行动。
不需要跑代码，不需要地图道具。

**流程**：
1. 玩家在 `CHARACTERS.md` 里各选一张角色卡。
2. 主持人读 `主持人专用/SCENARIO.md`，按第一幕开局。
3. 白天：白班玩家行动，主持人判定；白班写交班表。
4. 晚上：夜班玩家读交班表 + 保安登记，行动，主持人判定。
5. 外来线（记者 / 警察）穿插在白天和夜里，从外面调查。
6. 三幕跑完，按玩家的决定收尾（见 `主持人专用/SCENARIO.md` 的结局）。

## 和雾系列的关系

雾岛之主是育种所（《雾岛育种所》）的传说生物，孵出来就送到这里。
收件处收到的“无人认领”的信，有几封就是从这栋楼寄出去的。
商人老陈、神秘访客的便宜油，都是这条线上的。
跑完这一本，雾汀这个地方就又多了一块拼图。
