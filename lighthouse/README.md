# 《雾岛灯塔 · 守塔人》

资源经营带风险小游戏，给 AI 玩。你是雾岛灯塔的守塔人，要守满 30 夜。
手里有五种资源：燃油、雾币、粮食、灯塔状况、声望。

每天：先看发生什么事，再做两件事，入夜决定点灯。
灯亮着要烧油，不亮船就看不见；油价每天会变，有人半夜偷油。

每局 30–60 分钟。种子不同，事件、船期、油价、窃贼全变，可重复玩。

## 文件

| 文件 | 用途 |
|---|---|
| `game.py` | 游戏本体（纯 Python 3 标准库，无依赖） |

本目录不附带现成的答案文件。密封答案请在本地生成（见下）。

## 怎么玩

```bash
python3 game.py            # 默认种子 7
python3 game.py --seed 42  # 换个种子，新一局
```

**每天的流程**

1. **早上**：先看今天发生什么事。有的事自动发生（暴风雨、商船、浓雾、
   渔民送鱼、灯塔故障），有的事要你当场选（船只遇险救不救、神秘访客的
   便宜油买不买）。便宜油是掺了水的，烧得飞快 —— 访客不会告诉你。
2. **白天**：2 个行动点，选两件事做。
   - `买油`：5 单位燃油，按今天油价
   - `买粮`：5 单位粮食，10 雾币
   - `修缮`：灯塔状况 +15，10 雾币（也能修好故障）
   - `巡视`：找偷油的线索（集齐 3 条能认出窃贼）
   - `捕鱼`：粮食 +3
   - `休息`：灯塔状况 +5
   - `对质`：集齐 3 条线索后揭穿窃贼，偷油就停了
3. **夜里**：决定点灯。
   - `全亮`：3 燃油。有船经过，声望 +4、雾币 +6；浓雾夜声望再 +3。
   - `半亮`：1 燃油。有船经过，声望 +1。
   - `熄灯`：0 燃油。有船经过，声望 -12；浓雾夜 -18。
   - 你事先不知道今晚有没有船经过 —— 点灯就是一场赌。
4. **过夜**：吃 1 粮食（没粮了状况 -10、声望 -5），港务局考核声望 -2，
   偷油贼可能又来（燃油 -3），掺水油的效果递减。

其他命令：`status` 看状态，`ships` 看船期记录，`help` 看说明，`quit` 离开。

**船期背后可能藏着规律。** 输入 `ships` 能看到每晚有没有船经过
（●=有船，○=无船）。留心观察 —— 船来的日子可能不是随机的。
发现规律的人，能把油花在刀刃上：可能有船的夜里全亮，没船的夜里省油。
规律是种子定的，每局不一样，别指望上一局的规律这局还管用。

## 胜负 / 结局

- **留任（赢）**：守满 30 夜，且声望 >= 50。
- **撤职（输）**：声望 <= 0，或灯塔状况 <= 0，或连续 3 夜熄灯。
- **不续约（输）**：守满 30 夜，但声望 < 50。

## 自己生成一局

任选一个数字作为种子，在本目录运行：

```bash
python3 game.py --seed 数字 --export
```

这会在本地生成 `SEALED.md`（密封答案，玩家勿看）。换一个数字就是新一局，生成的文件只留在你自己的电脑上。本作没有网页 AI 用的开局提示或裁判手册，玩家直接运行 `game.py` 即可。

裁判如果需要核对，可看生成的 `SEALED.md`，或使用：

```bash
python3 game.py --seed 数字 --reveal   # 直接看这一局的真相（裁判用，玩家勿用）
```

另有 `--self-play`（自动打一局，用来验平衡）和 `--days`（默认 30 夜）。

## 注意

- 偷油的线索要靠 `巡视` 找：偷油发生后第二天巡视才能拿到新线索。
  3 条线索集齐才能 `对质`。窃贼是谁、哪几夜偷油，写在本地生成的 `SEALED.md` 里。
- 仓库里不附带 `SEALED.md`。本地生成的那份标明“玩家勿看”，请在打完本局后再打开。
