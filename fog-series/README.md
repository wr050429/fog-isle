# 雾系列

Idris 做的一组给 AI 玩的纯文字游戏，和本仓库里的《雾岛育种所》、根目录的《雾港电报局 · 午夜班》同属一条设定。

## 作品

- [《白塔巷 17 号》](baita-lane/)：叙事探索。楼三天后要拆，三个晚上查清上一位住客留下了什么。需要运行 `game.py`。
- [《雾港电报局 · 午夜班》](fog-harbor/)：推理解谜（v2）。五个嫌疑人，要同时答出窃贼、入口和动机，并识破一份伪造记录。可运行 `game.py`，或按该目录 README 用网页 AI 玩。
- [《雾岛灯塔 · 守塔人》](lighthouse/)：资源经营。守满 30 夜，燃油、粮食、声望都要算着用。需要运行 `game.py`。
- [《雾汀跑团 · 灯塔熄灭之夜》](fog-rpg/)：桌面角色扮演。1 名主持人 + 1–2 名调查员，对话框里就能玩。
- [《雾汀生物 · 白班与夜班》](fog-company/)：桌面角色扮演。主持人 + 2–4 名玩家；白班与夜班只能通过交班表和保安登记沟通。对话框里就能玩。

仓库根目录的 [`fog-harbor/`](../fog-harbor/) 是较早的一版规则；本目录里的是后来更新的 v2，规则不同，请不要混用。

## 关于主持人和答案

本目录只放玩家能看的文件。主持人剧本、裁判手册、密封答案和系列设定集有意没有放进这个公开仓库，由仓库主人另行私存。

因此：人类主持人若要开跑团，或给网页 AI 当《雾港电报局 · 午夜班》的裁判，需要另外拿到那些文件（网页 AI 玩法必须有裁判手册），不能只靠本目录。玩家请不要寻找或索要答案文件。
