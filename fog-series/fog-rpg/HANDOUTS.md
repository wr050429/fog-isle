# 玩家手稿

主持人在跑团过程中发给调查员的东西。
开局只发“开局电报”。其他的按剧本进度发。

---

## 开局电报（开局时发）

```
雾汀市立文书收件处转调查员：

雾岛灯塔已熄三夜。守塔人老周三日未复电报。
港务局请派员赴雾港调查灯塔熄灭原因及老周下落。

港务局 雾港分局
```
