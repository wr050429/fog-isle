# 《雾汀跑团 · 灯塔熄灭之夜》

雾系列的跑团游戏（桌面角色扮演）。主持人 + 1–2 名调查员，
三幕调查，约 2–3 小时（可分两次跑完）。

雾岛的灯塔熄了三夜。守塔人老周失踪了。港务局发了一封电报到雾汀市，
请求派人调查。你和你的搭档来到雾港，查清楚灯塔为什么熄了、
老周去了哪里。

## 文件

| 文件 | 给谁 | 用途 |
|---|---|---|
| `README.md` | 所有人 | 本文件：这是什么、怎么玩 |
| `RULEBOOK.md` | 所有人 | 规则：属性、技能、骰子、理智、幸运 |
| `CHARACTERS.md` | 玩家 | 四张预设调查员角色卡，选一张 |
| `HANDOUTS.md` | 玩家（主持人发） | 开局电报、雾汀地图、调查中会拿到的手稿 |
| `ADVENTURE.md` | **主持人专用** | 剧本：三幕、场景、NPC、线索、真相 |
| `SEALED.md` | **主持人专用** | 真相速查：谁干的、为什么、怎么收尾 |

**玩家不要看 `ADVENTURE.md` 和 `SEALED.md`。** 看了就没得玩了。

## 怎么玩

**人**：一名主持人（人类或 AI），1–2 名调查员（Arsland、幕僚长）。
主持人讲场景、扮演 NPC、掷骰子判定；调查员说自己要做什么。

**在哪里玩**：对话框里就能玩。主持人把场景描述贴过去，
调查员回一句“我要做什么”，主持人按规则判定、讲结果。
不需要跑代码，不需要地图道具。骰子由主持人掷（或用 `/roll` 之类的工具）。

**流程**：
1. 调查员在 `CHARACTERS.md` 里各选一张角色卡。
2. 主持人读 `ADVENTURE.md`，把 `HANDOUTS.md` 里的“开局电报”贴给调查员，开局。
3. 按 `RULEBOOK.md` 掷骰子判定。调查员每回合说一件事要做，
   主持人判定成败、讲结果、给线索。
4. 三幕跑完，按调查员的决定收尾（见 `ADVENTURE.md` 的结局）。

## 这是什么风格

调查，不是战斗。雾系列的调子：雾、灯、信、夜班、暂缓结案。
紧张感来自“对不上”，不是来自“打不过”。
没有跳脸的怪物，没有血浆。最吓人的东西，是发现灯塔的油被人换了，
而换油的人就坐在你对面喝酒。

## 和雾系列的关系

地点、人物、暗线都和系列手册（`../SERIES.md`）通着：
雾港（海关、电报局、酒馆）、雾岛（灯塔）、雾汀市（收件处）。
陈聿、老周、沈小姐、林老板、商人老陈都是手册里的人。
跑完这一本，雾汀这个地方就又多了一块拼图。
