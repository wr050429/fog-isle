# 《雾汀生物》规则书

轻量 d100 检定规则，给 AI 跑团用。主持人掷骰子，玩家说行动。
和《灯塔熄灭之夜》同一套底子，多了交班表、保安登记、昼夜循环。

## 一、属性与技能

每名玩家有五项属性（30–80），写在角色卡上：
体魄、敏捷、观察、推理、意志。

技能 = 属性 + 加成，角色卡上已经算好了，直接用。
常用技能：侦查（观察）、聆听（观察）、图书馆（推理）、
说服（意志）、潜行（敏捷）、急救（推理）、机械（推理）、
会计（推理，查账）、交涉（意志，谈判）。

## 二、掷骰子

**检定**：掷 1d100。结果 <= 技能值 = 成功；> 技能值 = 失败。
- **大成功**：结果 <= 技能值 / 5。主持人给额外信息或好处。
- **大失败**：结果 96–100。主持人给坏结果。
- **对抗**：双方各掷一次，比成功程度。

**难度**：普通直接掷；困难技能值减半；简单技能值 +20（上限 95）。

**幸运**：每名玩家开局 10 点。花 1 点重掷一次自己的检定，
或花 2 点把一次失败改成成功（不能改大失败）。整本剧本不补充。

**理智**：开局 60。遇到“不对劲”的东西做意志检定：
成功理智 -1，失败 -1d6，大失败 -1d10。理智到 0 会崩溃，
本幕由主持人接管，跑完本幕后恢复到 10。

## 三、交班表（白班与夜班之间的唯一通道）

这是这个游戏的核心规则。

**白班怎么写**：
白班玩家在白天结束时写交班表（主持人给模板，见 `HANDOUTS.md`）。
交班表有固定栏目：时间、地点、事件、处理、备注。
白班玩家可以：
- 如实写（最安全，夜班有好信息）。
- 漏写（某件事不写，夜班就不知道）。
- 撒谎（写一件没发生的事，或把一件事写成另一件）。
- 写含糊话（“3 号饲养室有点不对劲”，不说具体怎么不对劲）。

主持人要提醒白班玩家：你写的东西，夜班玩家会照着做。
你漏了、撒谎了，夜班可能会出事，也可能反过来发现你在撒谎。

**夜班怎么读**：
夜班玩家读交班表，也读**保安登记**（客观记录，主持人给）。
保安登记写的是：谁、几点、进出、带了什么走。它是机器记的，
不会撒谎。夜班玩家要对照两份记录找矛盾：
- 交班表说“陈默 17:00 下班走了”，保安登记说“陈默 23:00 才走，
  还带了一只箱子”——有人在撒谎。
- 交班表没写“3 号饲养室警报响了”，但保安登记说“02:00 有人进了
  3 号饲养室”——白班漏了，或者不敢写。

**检定**：夜班玩家想从交班表里看出破绽，掷`推理`。
成功：主持人指出一处矛盾。失败：主持人只说“表上看着没什么问题”，
玩家要自己再想办法（去现场看、问人、查监控）。

## 四、保安登记

保安登记是客观的，不会撒谎，但它只记“谁、几点、进出、带了什么”，
不记“为什么”。主持人按剧本给登记内容。
夜班玩家可以随时要求看保安登记（不需要检定，直接给）。
但保安登记只覆盖大门和饲养室门口，别的地方没有登记。

## 五、昼夜循环

一局分三幕，每幕分白天和夜里：

- **白天**：白班玩家行动（处理日常、应付来访、写交班表）。
  记者、警察玩家也在白天行动（从外面调查）。
- **夜里**：夜班玩家行动（读交班表、查异常、处理饲养室）。
  记者、警察玩家可以在夜里蹲点、跟踪。

主持人按“白天 → 夜里 → 白天 → 夜里”的顺序推进。
白班玩家在夜里不在场（他下班了），夜班玩家在白天不在场
（他在睡觉）。两个人只能通过交班表交流——主持人把白班写好的
交班表贴给夜班，夜班再行动。两个人不能直接对话（除非打电话，
打电话要过`说服`，而且电话里说不清）。

## 六、异常

夜里会发生异常（主持人按剧本安排，或掷骰子决定）：
- 饲养室警报响了。
- 雾岛之主躁动，撞笼子。
- 一扇本该锁着的门开了。
- 监控里出现一个不该出现的人影。
- 雾从饲养室的通风口渗进来。

夜班玩家要处理异常。处理方式由玩家自己想（去看、去修、去安抚、
去报警），主持人按规则判定。异常处理不好会升级（小异常变大事故）。

## 七、调查的规矩（三线索原则）

每个关键结论，剧本里至少有三条线索指向它。玩家卡住了，
主持人可以：让玩家做一次`推理`检定（成功给新线索）、
让 NPC 主动开口、把已拿到的线索重新讲一遍。
检定失败 = 拿到线索但付出代价（花时间、被人看见、东西坏了），
不是“什么都没找到”。

## 八、战斗（尽量别打）

这本剧本里几乎没有战斗。如果玩家非要动手：攻击方掷体魄或敏捷，
防守方掷敏捷对抗，胜者造成 1d6 伤害。体魄到 0 倒下，需要急救。
主持人有权说“打起来了，但这不是办法”。
