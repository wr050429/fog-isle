# 玩家手稿

主持人在跑团过程中发给玩家的东西。
开局只发“公司地图”。其他的按剧本进度发。

---

## 公司地图（开局时发）

```
雾汀生物 · 公司地图

三楼：饲养室（雾岛之主）· 研究员办公室 · 主任办公室
二楼：化验室 · 药房 · 会议室
一楼：大门（保安登记处）· 接待处 · 仓库
地下室：储藏间 · 锅炉房
```

---

## 交班表模板（第一幕结束，白班写，主持人发给白班）

```
雾汀生物 · 交班表

白班值班员：________
日期：________

| 时间 | 地点 | 事件 | 处理 | 备注 |
|------|------|------|------|------|
|      |      |      |      |      |
|      |      |      |      |      |
|      |      |      |      |      |

交班人签字：________
```

白班玩家按模板写。写什么、漏什么、撒什么谎，由白班玩家自己决定。
写完交给主持人，主持人贴给夜班玩家。

---

## 保安登记（第二幕，夜班读，主持人发）

```
雾汀生物 · 保安登记（大门）

08:00 林晚进（白班值班员）
08:15 主任进
09:00 老陈进，带一只箱子
09:30 记者白露进（来访，11:00 出）
10:00 警察顾衡进（来访，11:30 出）
12:00 老陈出
17:00 林晚出（白班下班）
23:00 陈默出，带一只箱子（！）
23:05 保安（老陈的人）出，带一只箱子（！）
02:00 有人进 3 号饲养室（！）
```

保安登记是客观的，不会撒谎。但它只记“谁、几点、进出、带了什么”，
不记“为什么”。

## 主任的备忘录（第一幕·主任办公室，主持人发）

```
备忘录

陈默请假三天，有事找我。

主任
```

字迹很新，像是刚写的。日期是今天。

## 化验单（第一幕·陈默的桌子，主持人发）
