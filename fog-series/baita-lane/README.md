# 《白塔巷 17 号》

叙事分支 / 探索小游戏，给 AI 玩。你刚搬进白塔巷 17 号 302 室 ——
上一位住客陈聿的房间。这栋楼三天后要拆了。
你有三个晚上，弄清楚陈聿留下了什么、以及他为什么半夜总往屋顶和地下室跑。

每局 20–40 分钟。**真相由种子定，可重复玩。**

## v2：三个真相变体

种子会抽一个变体。信、笔记本、王阿姨、老李、信号灯、结局都跟着变。
换种子，就是一个新的谜。

| 变体 | 陈聿是谁 | 笔记本是什么 | 屋顶的信号是什么意思 |
|---|---|---|---|
| A 收件员 | 收件处的夜班值班员 | 值班日志（收件记录） | 三长两短是“收到了” |
| B 藏人 | 在 301 里藏了一个人 | 送饭和放哨的时间表 | 灯亮着是“安全” |
| C 走私 | 一个中间人 | 账本（日期、货名、接货人） | 灯亮着是“可以靠岸” |

默认种子 7 是变体 B（藏人）。

## 文件

| 文件 | 用途 |
|---|---|
| `game.py` | 游戏本体（纯 Python 3 标准库，无依赖） |
| `SEALED.md` | **密封：玩家勿看** —— 本局真相（变体、六条主要线索、结局条件） |

## 怎么玩

```bash
python3 game.py            # 默认种子 7（变体 B）
python3 game.py --seed 1   # 变体 A
python3 game.py --seed 5   # 变体 C
```

**输入**

- 输入数字选行动（比如 `1` 就是做列表里的第 1 件事）
- 输入 `去 201`、`去 地下室`、`去 屋顶` 这样的地点可以走动（走动不花行动点）
- 输入 `线索` 看已经找到的线索
- 输入 `决定` 可以提前做最后的决定
- 输入 `quit` 离开

**行动点**

每晚 4 个行动点，三晚共 12 个。看东西、问人、拿东西、开箱子各花 1 点。
东西很多，时间不够 —— 你得选。有的行动要先拿到别的东西才能做
（比如地下室那只刻着“陈聿”的木箱，要先在 302 的抽屉里找到钥匙）。

**地点**：302（你的房间）、201（王阿姨家）、202（老李家）、
301（锁着的房间）、地下室、屋顶、院子。

## 胜负 / 结局

结局由你找到的线索和最后的决定共同决定。六条主要线索：

1. 陈聿的信（302 桌上）
2. 王阿姨的话（201）
3. 老李的话（202）
4. 陈聿的笔记本（地下室木箱，需钥匙）
5. 真相（读笔记本；名字随变体变：收件处的真相 / 藏人的真相 / 走私的真相）
6. 屋顶的信号（屋顶）

- **A 接手**：有笔记本 + 屋顶的信号。按本局的真相接手陈聿留下的事。
- **B 上交**：有笔记本，把笔记本交给房东。
- **C 离开**：没有笔记本，或选择离开。
- **E 真相**：集齐全部六条主要线索，拼出完整真相，再做决定。

301 室在变体 A 和 C 里和他无关，在变体 B 里藏着一个人——
钥匙打不开它，敲门也没用，只能贴在门上听。

## 换一局

```bash
python3 game.py --seed 123 --export   # 生成新一局的 SEALED.md
python3 game.py --seed 123 --reveal   # 直接看新一局的变体和真相（裁判用，玩家勿用）
```
