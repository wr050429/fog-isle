# 雾岛育种所 Fog Island Breeding Station

给两个 AI 玩的文字育种游戏。纯 Python 3 标准库，零依赖。

## 为什么做这个游戏

上一局养殖游戏玩到后面没意思了：规则固定且全公开，摸透之后只剩重复执行，
可玩性下降。这个游戏专治「后面没有未知」：

1. **每季基因系统重新随机**：性状、显隐性、基因互作都由种子决定，
   上一季摸透的规律，下一季不成立。
2. **基因型藏起来**：你只能看到雾兽的外观（表现型），看不到基因型；
   隐性携带者不可见，必须靠杂交后代去推断。
3. **图鉴里全是「???」**：看得见的未知边界。性状被发现后，还会揭示
   它背后的隐藏规则（显性 / 隐性 / 不完全显性 / 上位）。
4. **持续注入新未知**：随机事件、神秘蛋、市场轮换、委托不断带来新东西。
5. **传说目标每季随机**：培育出「雾岛之主」需要 3 个稀有性状，
   条件藏在图鉴里，随相关性状被发现而逐步揭示。

## 玩法

两人合作制：A 和 B 各管一个育种所，共享图鉴、市场和传说目标。
一季 30 天，每天每人 2 个行动点。共同目标是培育出传说「雾岛之主」。

```bash
python3 play.py            # 开始游戏（随机种子）
python3 play.py --seed 7   # 指定种子（同一种子 = 同一局，方便复现/分享）
python3 play.py --self-play --days 30 --seed 7   # 自动玩演示
```

### 命令

| 命令 | 说明 | 行动点 |
| --- | --- | --- |
| `status` | 查看自己的育种所 | 免费 |
| `state` | 查看完整状态（适合粘贴到聊天） | 免费 |
| `codex` | 查看图鉴（已发现 + ???） | 免费 |
| `market` | 查看市场 | 免费 |
| `commission` | 查看委托 | 免费 |
| `offers` | 查看待处理交易和借配请求 | 免费 |
| `breed <id1> <id2>` | 繁殖两只雾兽 | 1 |
| `borrow <A\|B> <id>` | 向对方借一只雾兽配种 | 1 |
| `borrow-accept <请求id>` / `borrow-decline <请求id>` | 回应借配 | 免费 |
| `buy <市场id>` | 买市场雾兽（基因未知，买是赌） | 1 |
| `sell <id>` | 卖雾兽给市场 | 1 |
| `trade offer <我的id> for <对方id> [雾币]` | 发起交易 | 1 |
| `trade accept <交易id>` / `trade decline <交易id>` | 回应交易 | 免费 |
| `explore` | 探索岛屿（野雾兽 / 神秘蛋 / 雾币 / 无功而返） | 1 |
| `claim <委托id>` | 完成委托 | 1 |
| `egg` | 买神秘蛋（20 雾币，仅当有蛋时） | 1 |
| `name <id> <名字>` | 给雾兽命名 | 免费 |
| `end` | 结束回合 | 免费 |
| `save <文件>` / `load <文件>` | 存档 / 读档 | 免费 |
| `new [种子]` | 新一季 | 免费 |
| `help` | 帮助 | 免费 |

### 在聊天里玩

裁判（其中一位玩家或第三方）运行 `python3 play.py`，每回合把 `state` 的
输出贴到聊天里，两位玩家在聊天里发命令，裁判输入命令、把结果贴回来。
基因型只存在存档里，裁判程序只显示表现型——别偷看存档。

## 机制速览

- **基因**：6 个位点（体型 / 毛色 / 角 / 翼 / 尾 / 光），每位点 3–4 个
  常见等位基因 + 1–2 个稀有等位基因（只能通过突变、市场或神秘蛋获得）。
- **表达规则**：每位点每季随机为显性 / 隐性 / 不完全显性 / 上位四种之一。
- **繁殖**：孟德尔分离，每位点 4% 突变率；同种得同种，异种得杂交种。
- **图鉴**：性状 + 物种，未发现显示「???」；发现性状后揭示其规则。
- **市场**：轮换待售雾兽（只显示外观）；委托要求特定性状，完成后得雾币。
- **事件**：每晚随机一件（雾夜 / 神秘商人 / 流浪雾兽 / 丰收 / 雾疫 /
  神秘蛋 / 横财 / 访客 / 雾潮 / 静夜）。
- **传说**：每季随机 3 个稀有性状，同时表达在一只雾兽身上即胜利（两人共同胜利）。
- **季末**：30 天未达成则结算（图鉴进度 + 雾兽数 + 雾币 = 得分），
  `new [种子]` 开始新一季。

## 文件结构

```
fog_isle/
  genetics.py    基因、性状、表达规则、表现型计算
  creatures.py   雾兽、繁殖、突变、物种
  codex.py       图鉴
  events.py      随机事件
  market.py      市场、委托、交易
  game.py        游戏状态、回合、命令解析、存档
  cli.py         命令行界面（交互 + 自动玩）
play.py          入口
tests/
  test_game.py   单元测试（四种表达规则、繁殖、突变、图鉴、传说、交易、存档）
  smoke_play.py  冒烟测试（随机策略跑满一季）
DESIGN.md        设计文档
```
