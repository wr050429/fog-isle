# 雾岛 / 雾港

给 AI 玩的纯文字小游戏系列。

## 游戏

- [《雾港电报局 · 午夜班》](fog-harbor/)：推理解谜。海关保险箱夜里被取走，七个嫌疑人各有口供。需要两份记录交叉验证才能定罪。最多读 6 份，提问 2 次，指认 3 次。
- [《雾港电报局 · 午夜班》v2](fog-harbor-v2/)：同一标题的另一版规则（五个嫌疑人，要同时答出窃贼、入口和动机）。与上一则不要混用。
- [《雾岛育种所》](fog_isle/)：两人合作育种。每季基因系统重新随机，只能看到外观，看不到基因型。目标是培育出传说「雾岛之主」。
- [《雾岛灯塔 · 守塔人》](lighthouse/)：资源经营。守满 30 夜，燃油、粮食、声望都得算着用。
- [《白塔巷 17 号》](baita-lane/)：叙事探索。楼三天后拆除，三个晚上 12 个行动点。
- [《雾汀跑团 · 灯塔熄灭之夜》](fog-rpg/)：桌面角色扮演。1 名主持人 + 1–2 名调查员。
- [《雾汀生物 · 白班与夜班》](fog-company/)：桌面角色扮演。主持人 + 2–4 名玩家。

## 雾港电报局 · 给网页 AI 玩

1. 本地运行 `python3 fog-harbor/game.py --seed 42 --export` 生成一局（v2 则进入 `fog-harbor-v2/`）。
2. 把生成的 `PROMPT.md` 贴给玩家 AI。
3. 玩家说「读 N 号」时，从 `REFEREE.md` 里把对应记录贴过去。
4. 不要把 `REFEREE.md` 或 `SEALED.md` 本身贴给玩家。

仓库里不附带预生成的开局或答案，请自己选一个数字。换数字就是新一局。

## 自己生成一局（代码游戏）

任选一个数字，在对应目录运行：

```bash
python3 game.py --seed 数字 --export
```

- `fog-harbor/`、`fog-harbor-v2/`：生成 `PROMPT.md`、`REFEREE.md`、`SEALED.md`。裁判留下后两份，只把 `PROMPT.md` 给玩家。
- `baita-lane/`、`lighthouse/`：只生成 `SEALED.md`。这两作没有网页 AI 用的开局提示和裁判手册，玩家直接运行 `game.py`。
