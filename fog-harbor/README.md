# 《雾港电报局 · 午夜班》

> **警告：本游戏极其硬核。**
>
> 不要用常规线性逻辑去硬推。有些记录是用来洗白好人的，有些软记录是用来锁死真凶的。单份记录不能定罪，需要两份交叉验证。请做好被系统玩弄的心理准备。

推理 / 解谜小游戏，给 AI 玩。雾港海关的保险箱在夜里被人从仓库取走了。七个嫌疑人各有一份口供，另有一批记录。你的任务是找出窃贼，并用**两份记录**证明他撒谎。

每局 20–40 分钟。种子不同，窃贼、作案时刻、关键证据全变，可重复玩。

## 文件

| 文件 | 用途 |
|---|---|
| `game.py` | 游戏本体（纯 Python 3 标准库，无依赖） |
| `PROMPT.md` | 给网页 AI 玩家的开局提示词（`--export` 后生成） |
| `REFEREE.md` | 裁判手册（`--export` 后生成，含全部记录） |
| `SEALED.md` | **密封：玩家勿看**（`--export` 后生成，含真相） |

## 自己生成一局

仓库里不附带预生成的开局提示、裁判手册或答案。任选一个数字作为种子，在本目录运行：

```bash
python3 game.py --seed 数字 --export
```

这会在本地生成 `PROMPT.md`、`REFEREE.md` 和 `SEALED.md`。换一个数字就是新一局，生成的文件只留在你自己的电脑上。

裁判留下 `REFEREE.md` 和 `SEALED.md`，只把 `PROMPT.md` 给玩家或网页 AI。

```bash
python3 game.py --seed 数字 --reveal   # 看真相（上帝复盘模式，裁判用）
```

- 把 `PROMPT.md` 贴给玩家 AI。
- 玩家说「读 N 号」，把 `REFEREE.md` 里对应的记录原文贴回去。
- 指认格式：`人名 + 记录A + 记录B`。
- 最多读 6 份，提问 2 次，指认 3 次。
- 不要把 `REFEREE.md` 或 `SEALED.md` 本身贴给玩家。

## 机制说明

- **硬记录**：有签字，能确认身份与地点。不自动证明犯罪。
- **软记录**：只确认「某时段有人在某地点附近」，不带名字。不能单独确认身份。
- **干扰记录**：无签字、无佐证，不得作为事实依据。
- 关键证据可能不带名字。需要用时间点 + 地图 + 口供交叉锁定身份。
- 地图公开：六个地点连成一圈，相邻约 30 分钟，不相邻约 60 分钟。
