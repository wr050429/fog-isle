# 《雾汀跑团》规则书

轻量 d100 检定规则，给 AI 跑团用。主持人掷骰子，调查员说行动。

## 一、属性

每名调查员有五项属性（30–80），写在角色卡上：

| 属性 | 管什么 |
|---|---|
| 体魄 | 力气、耐力、抗住打击 |
| 敏捷 | 身手、躲闪、潜行、爬高 |
| 观察 | 眼力、耳力、发现细节 |
| 推理 | 逻辑、联想、拼凑线索 |
| 意志 | 胆量、定力、抗住恐惧 |

## 二、技能

技能 = 属性 + 加成。角色卡上已经算好了，直接用。
常用技能：

| 技能 | 基于 | 用来 |
|---|---|---|
| 侦查 | 观察 | 找东西、找线索、搜房间 |
| 聆听 | 观察 | 听动静、听出话外音 |
| 图书馆 | 推理 | 查档案、查记录、翻旧报纸 |
| 说服 | 意志 | 让人开口、套话、谈判 |
| 潜行 | 敏捷 | 跟踪、不被发现、悄悄溜进去 |
| 急救 | 推理 | 包扎、看伤、判断死因 |
| 航海 | 敏捷 | 开船、认水路、看天气 |
| 机械 | 推理 | 修东西、开锁、看懂机器 |

主持人可以按需加新技能（比如“会计”查账本、“神秘学”认符号），
基础值 = 对应属性的一半。

## 三、掷骰子

**检定**：掷 1d100（1–100）。结果 <= 技能值 = 成功；> 技能值 = 失败。

- **大成功**：结果 <= 技能值 / 5（向下取整）。主持人给额外信息或好处。
- **大失败**：结果 96–100。主持人给坏结果（东西弄坏了、被人发现了、线索断了）。
- **对抗**：双方各掷一次，比“成功程度”（成功且数字更小者胜；
  一方成功一方失败，成功者胜；都失败，都失败）。

**难度**：
- 普通：直接掷。
- 困难：技能值减半再掷（主持人说“困难检定”）。
- 简单：技能值加 20 再掷（上限 95）。

**幸运**：每名调查员开局有 10 点幸运。可以花 1 点幸运重掷一次
（只重掷自己的检定），或花 2 点把一次失败改成成功
（不能改大失败）。幸运用完就没了，整本剧本不补充。

## 四、理智

理智开局 60。每当调查员遇到“不对劲”的东西（尸体、被撬的锁、
半夜的脚步声、写给你的字条……），主持人让调查员做一次意志检定：

- 成功：理智 -1。
- 失败：理智 -1d6。
- 大失败：理智 -1d10。

理智降到 0：调查员崩溃了，本幕剩下的时间由主持人接管
（他会发抖、胡言乱语、或者转身就跑）。跑完本幕后恢复到 10，
可以继续玩。

理智不是血条，是“这地方有多不对劲”的刻度。别把它当战斗用。

## 五、调查的规矩（三线索原则）

每个关键结论，剧本里至少有三条线索指向它。调查员卡住了，
主持人可以：
- 让调查员做一次“推理”检定，成功就给一条新线索；
- 让某个 NPC 主动开口（“其实我还看见……”）；
- 把调查员已经拿到的线索重新讲一遍，帮他们拼起来。

**不要让调查员因为一次掷骰失败就卡死。** 检定失败 = 拿到线索但付出代价
（花了更多时间、被人看见了、东西弄坏了），不是“什么都没找到”。

## 六、战斗（尽量别打）

这本剧本里几乎没有战斗。如果调查员非要动手：
- 攻击方掷“体魄”或“敏捷”，防守方掷“敏捷”对抗。
- 胜者造成 1d6 伤害（体魄 -1d6）。体魄到 0 就倒下，需要急救。
- 主持人有权说“打起来了，但这不是办法”——雾系列不靠拳头破案。

## 七、主持人掷骰子

主持人替所有 NPC 掷骰子，也替调查员掷（调查员说“我要侦查”，
主持人掷 1d100、对照技能、讲结果）。骰子结果要公开说出来
（“你掷了 42，侦查 60，成功”），别暗掷。
