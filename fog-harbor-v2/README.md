# 《雾港电报局 · 午夜班》

推理 / 解谜小游戏，给 AI 玩。雾港海关的保险箱在夜里被人从仓库取走了。
五个嫌疑人各有一份口供，另有一批记录写明了某些人在某些时刻的去向。

每局 20–40 分钟。种子不同，窃贼、作案时刻、手法、动机、伪造记录全变，
可重复玩。

## v2：三道题 + 一份伪造记录

v1 只找一处矛盾，对 AI 太简单了。v2 要答三道题，缺一不可：

| 题 | 问什么 | 证据 |
|---|---|---|
| 谁 | 窃贼是谁 | 口供 vs 记录的矛盾（关键证据） |
| 怎么进的 | 从哪进的、用的什么工具 | 现场勘查（后门 / 窗户 / 正门） |
| 为什么 | 动机是什么 | 窃贼名下的一份文书（赌债 / 治病 / 要挟） |

**还有一份伪造记录。** 窃贼栽赃给一个无辜者，伪造了一份
“他在仓库”的记录。别被它带偏 —— 那个无辜者另有一份不在场证明，
同一时刻、同一人、两个地方，所以伪造的那份是假的。
先找出哪份记录是伪造的，再找真凶。

## 文件

| 文件 | 用途 |
|---|---|
| `game.py` | 游戏本体（纯 Python 3 标准库，无依赖） |

本目录不附带预生成的开局提示、裁判手册或答案。请按下面的方法在本地生成。

## 玩法 A：命令行（能跑代码的 AI）

```bash
python3 game.py            # 默认种子 7
python3 game.py --seed 42  # 换个种子，新一局
```

命令：

- `list` —— 列出所有记录
- `read <编号>` —— 读一份记录，比如 `read 4`
- `timelines` —— 再看口供汇总
- `submit <人名> <入口> <动机>` —— 指认三道题，比如 `submit 小陈 后门 赌债`
  - 入口：后门 / 窗户 / 正门
  - 动机：赌债 / 治病 / 要挟
- `hint` —— 要一次提示（整局一次）
- `help` / `quit`

指认错了会告诉你哪几道题错了（人 / 手法 / 动机），不说答案。
3 次指认机会。

## 玩法 B：网页 AI（DeepSeek / ChatGPT，只能对话框聊天）

先按「自己生成一局」在本地生成文件。不需要给网页 AI 跑代码，一个人（或另一个 AI）当裁判：

1. 裁判把本地生成的 `PROMPT.md` 全文粘贴给玩家 AI，开局。
2. 玩家说“读 N 号”，裁判就把 `REFEREE.md` 里对应编号的记录全文贴过去，
   一次只贴一份。
3. 玩家说“指认：人名 + 入口 + 动机”，裁判按 `REFEREE.md` 的核对口令判断：
   告诉他哪几道题对了、哪几道题错了，不说答案。
4. 破案后，裁判可以把 `SEALED.md` 的真相部分贴给玩家作结尾。

裁判不要把 `REFEREE.md`、`SEALED.md` 本身贴给玩家。

## 胜负 / 结局

- **破案**：一次指认里，人、入口、动机三道题都对。游戏结束。
- **失败**：3 次指认机会用完仍未破案。本局结束，可看 `SEALED.md`，
  或换个种子再来一局。
- 答案用 SHA-256 校验，程序里不存明文答案；种子不同，答案不同。

## 自己生成一局

任选一个数字作为种子，在本目录运行：

```bash
python3 game.py --seed 数字 --export
```

这会在本地生成 `PROMPT.md`、`REFEREE.md` 和 `SEALED.md`。换一个数字就是新一局，生成的文件只留在你自己的电脑上。

裁判留下 `REFEREE.md` 和 `SEALED.md`，只把 `PROMPT.md` 给玩家或网页 AI。

```bash
python3 game.py --seed 数字 --reveal   # 直接看这一局的真相（裁判用，玩家勿用）
```

## 注意

- 伪造记录是唯一的“假矛盾”，关键证据是唯一的“真矛盾”。
  识破伪造的办法：找那个被栽赃的人在同一时刻的另一份记录。
- 仓库里不附带 `SEALED.md`。本地生成的那份标明“玩家勿看”，请在破案后再打开。
- 本作与仓库根目录的 [`fog-harbor/`](../fog-harbor/) 是同一标题的不同规则版本，请不要混用。
